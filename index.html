Machine Learning · Academic Project

Customer Churn Prediction

Overview. A supervised machine learning pipeline that predicts customer churn on the IBM Telco Customer Churn dataset (7,043 customers).

Problem. Identify customers likely to leave, so retention effort can be aimed where it matters.

  1. Data validation, cleaning and exploratory data analysis, with 10 engineered features.
  2. Scikit-learn Pipelines and ColumnTransformer (imputation, scaling, one-hot encoding), fitted on training data only.
  3. Stratified 70/15/15 train/validation/test split.
  4. Logistic Regression, Random Forest and HistGradientBoosting compared with 5-fold stratified cross-validation, GridSearchCV and RandomizedSearchCV.
  5. Logistic Regression and a 0.35 decision threshold selected using validation data only.
  6. Held-out test set scored once; joblib model, prediction script and pytest suite added.

EXPERIMENTAL

Expert Advisor Bot

Python · Trading Automation

Overview. A Python project that connects to a MetaTrader 5 terminal and evaluates market data through four concurrent trading pipelines, using price-action analysis and built-in risk controls.

  1. Four concurrent pipelines — scalping, intraday, swing and red-news — each with its own signal and confirmation logic.
  2. Price-action analysis: market structure (BOS/CHoCH), supply and demand zones, fair value gaps, liquidity conditions and candlestick patterns.
  3. Risk controls: risk-based lot sizing (capped at 1.5% per trade for metals and 2% for forex), drawdown-based risk reduction, per-pipeline position limits, spread and stop-loss checks.
  4. Trade management and records: break-even and partial-close logic, session and holiday checks, Forex Factory calendar filtering, CSV trade memory and email performance reports.

Status. Experimental, built for demo-account testing. No backtest or performance results are claimed.
